If a game won't open

These games aren't code-signed yet, so both systems warn you the first time you run one.

Windows: unzip, then run the .exe inside. If you see "Windows protected your PC", click More info, then Run anyway.

Mac: unzip, then right-click the app and choose Open. If macOS says it is damaged or blocked, go to System Settings > Privacy & Security and click Open Anyway.

The Mac builds don't run on Intel Macs.
