Tuff Jet

A top-down jet shooter. Dodge debris, shoot down enemy fighters, and spend your coins on eight upgrades.

Version 1.0, still in development.

Download

Download for Windows TuffJet-windows.zip, about 14 MB Download for Mac Apple Silicon (M1 and later), about 48 MB

Controls

Move
Arrow keys or W A S D
Fire
Space
Upgrades
U opens the shop, then 1 to 8 buys
Restart
R after game over
Quit
Esc

Progress resets every time you close the game.

If it won't open

The game isn't code-signed yet, so both systems warn you the first time.

Windows: unzip, then run TuffJet.exe. If you see "Windows protected your PC", click More info, then Run anyway.

Mac: unzip, then right-click the app and choose Open. If macOS says it is damaged or blocked, go to System Settings > Privacy & Security and click Open Anyway.

The Mac build doesn't run on Intel Macs.
